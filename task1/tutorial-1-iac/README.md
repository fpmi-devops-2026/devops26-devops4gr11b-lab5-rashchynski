# Руководство 1. What is Infrastructure as Code with Terraform?

Это вводное (интерактивное) руководство: в нём нет конфигурационных файлов Terraform.
Оно объясняет, что такое Infrastructure as Code (IaC), зачем описывать инфраструктуру
кодом и какие задачи решает Terraform:

- инфраструктура описывается декларативно и хранится в системе контроля версий;
- один и тот же код воспроизводит одинаковую инфраструктуру в разных окружениях;
- изменения проходят через `plan` (предпросмотр) и `apply` (применение);
- Terraform отслеживает созданные ресурсы в файле состояния (state).
